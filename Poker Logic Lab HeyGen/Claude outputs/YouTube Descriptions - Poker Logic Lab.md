How these are built for search and answer engines:

- The first line of every description is the hook plus the primary keyword, because YouTube shows only the first 100 to 150 characters in search and on the Shorts feed before "more."
- Each description carries a short question-and-answer block. That is the text answer engines (Google AI Overviews, ChatGPT search, Perplexity) lift when someone asks the question the video answers.
- The link goes in the description. YouTube descriptions are clickable, unlike TikTok and Instagram captions.
- Hashtags: 3 to 5 per video. YouTube shows the first three above the title on Shorts. More than 15 and YouTube ignores all of them.
- Tags (Details > Show more > Tags) are listed separately per video. They still help YouTube with misspellings and close variants.
- All seven are under 60 seconds and 9:16, so YouTube will file them as Shorts automatically. Add #Shorts as the last hashtag so it is explicit.
